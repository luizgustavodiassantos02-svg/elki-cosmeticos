# Elki Cosméticos e Presentes

## Sobre o projeto
Site desenvolvido como trabalho acadêmico para a disciplina Projeto de Extensão Web – ENIAC.

O objetivo é divulgar produtos de beleza e facilitar a comunicação com os clientes.
